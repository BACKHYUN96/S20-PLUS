# 픽셀 트래픽 실기기 검증

2026-10-06. 기본 설치·실행·적용 및 0.4.0 동작은 사용자 보고로 확인했습니다. 아래 항목의 장시간 검증과 수치 측정은 아직 수행하지 않았습니다.

## 0.5.0 진단 사용

1. 앱에서 차량 12대, 속도 1배, 30fps를 설정하고 배경화면을 적용합니다.
2. 홈 화면에 30초 이상 머무른 뒤 앱을 열어 **최근 주행 진단**을 확인합니다. 복사 버튼으로 결과를 공유할 수 있습니다.
3. 앱을 열면 배경화면이 가려지므로 진단 상태가 중지됨인 것은 정상일 수 있습니다. 기록 시각을 확인합니다. 미리보기 엔진이 실제 배경화면의 기록을 덮어쓰지 않도록 구분했습니다.

프레임 제출 평균은 성공한 Canvas 제출의 시간 간격 기준입니다. 화면에 실제 표시된 FPS가 아니며, GPU/display 계층 프레임 드롭은 이 수치로 검증하지 않습니다. 평균 그리기 시간은 lockCanvas부터 제출까지의 시간이며 시뮬레이션·전체 시스템 부하를 포함하지 않습니다. 단일 프레임만 있으면 평균 빈도는 0으로 표시됩니다.

## 필수 기능 확인

- 차량 4/8/12대, 속도 0.5/1/1.5배, 15/30/60fps 각각 변경 후 눈에 띄는 변화 확인. 차량 수는 화면 밖까지 포함합니다.
- 앱을 닫고 다시 열어 설정 유지 확인.
- 화면을 끄고 30초 뒤 켜기: 장면 복구, 차량 순간 이동이나 멈춤, 크래시가 없는지 확인.
- 다른 앱을 30초 사용한 뒤 홈으로 복귀: 정상 주행 재개 확인.
- 휴대폰 절전 모드 켜기/끄기: 연동 옵션이 켜져 있을 때 제한이 최대 15fps로 바뀌고 해제 시 원래 선택값으로 돌아오는지 진단 기록 확인.
- 반복 프레임 중단은 아래 로그의 state=stopped/running, sample 타임스탬프로 조사합니다. 로그가 없다는 사실만으로 절전 성공을 확정하지 않습니다.
- 잠금화면 적용 지원 여부와 표시를 별도로 기록합니다. 홈 화면 성공을 잠금화면 성공으로 간주하지 않습니다.

## 로그 수집

노트북 PowerShell에서 화면을 껐다 켜고 다른 앱에 다녀온 뒤 실행합니다.

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" logcat -d -v time -s PixelTraffic:I '*:S'
```

저장소의 `pixel-traffic/tools/Collect-Diagnostics.ps1`은 기기 모델/API, 앱 버전, 앱 메모리, PixelTraffic 태그 로그를 별도 폴더에 수집합니다. 파일 내용을 검토한 뒤 실행할 수 있습니다. 루트 권한이나 설정 변경은 없고 로그를 지우지 않습니다. 이 스크립트는 현재 Windows/기기에서 실행 검증하지 않았습니다.

## 장시간 안정성과 전력 — 미검증

- 동일 밝기/네트워크/앱/온도/충전 조건에서 정적 배경화면과 픽셀 트래픽을 각각 15~30분 관찰합니다. 게임 등 다른 부하는 제외합니다.
- 15fps와 30fps의 배터리 변화와 발열, 차량 주행이 멈추는지 기록합니다. 시간·시작/종료 배터리·온도·충전 상태를 함께 기록합니다. 짧은 배터리 퍼센트 변화만으로 정확한 소비 전력을 계산하지 않습니다.
- 레드존의 CPU/GPU 최고 고정 등 기기 설정이 측정에 영향을 줍니다. 설정을 기록하고 비교 구간에서 동일하게 유지합니다. 이 검증을 위해 루트 설정을 자동 변경하지 않습니다.
- 충전 중 측정은 배터리 감소 비교에 적합하지 않습니다. ADB USB 연결·충전 유무가 다른 결과를 직접 비교하지 않습니다.
- 합격 판정은 실제 관찰 기록을 받은 후 합니다. 진단 기능 추가 자체를 안정성·전력 합격으로 기록하지 않습니다.

## 0.6.0 비교

같은 차량 수/속도/프레임/시간대/기기 상태에서 30초 이상 홈 화면에 머문 뒤 진단을 비교합니다. 0.5.0 사용자 스크린샷은 제한 60fps, 제출 평균 56.2fps, 그리기 8.20ms, 성공 프레임 614였습니다. 동일한 관찰 조건은 아직 확정되지 않았으므로 엄밀한 성능 기준점으로 단정하지 않습니다. 낮/저녁/밤 전환 후 차량 흐름과 설정 유지도 확인합니다.

## 0.8.0 기능 확인

자동 시간대를 켜고 현재 휴대폰 현지 시간이 06~17시이면 낮, 17~20시이면 노을, 나머지면 밤인지 확인합니다. 끄면 기존 수동 선택으로 돌아오는지 확인합니다. 시간 전환은 일반 사용에서 관찰하며 테스트를 위해 휴대폰 시계를 자동 변경하지 않습니다. 빠른 모드 3개 적용 후 차량 수·속도·프레임·절전 연동과 장면/날씨 유지, 앱 재실행 후 저장 여부를 확인합니다.

## 0.9.0 앱 안 미리보기 확인 (실행 대기)

1. 앱 상단에 장면 전체가 잘림 없이 표시되고 차량/비가 움직이는지 확인합니다. 미리보기는 15fps이며 홈 배경화면 프레임 설정과 독립적입니다.
2. 장면·날씨·차량 수·속도·자동 시간대를 바꿔 즉시 반영되는지 확인합니다. 차량 위치는 홈 화면과 다를 수 있습니다.
3. 진단 창 열기, 앱 백그라운드 전환, 화면 꺼짐/복귀에서 중지·재개가 정상인지 확인합니다. 미리보기만 실행해 실제 배경화면 진단이 덮어써지지 않는지도 확인합니다.
4. 빠른 모드로 화면이 재생성되어도 미리보기와 설정이 정상인지 확인하고 홈 배경화면에도 저장된 설정이 적용되는지 확인합니다.
5. 작은 화면/가로 방향에서 설정 스크롤이 가능한지 확인합니다. 추가 전력/발열은 아직 측정하지 않았습니다.

## 0.10.0 차량 아트 (실기기 확인 대기)

- 앱 미리보기와 홈 화면에서 차량 종류별 미러/지붕/택시 무늬/버스/화물칸이 정상 표시되는지 확인합니다. 먼 차량에서는 픽셀 축소로 작은 디테일이 생략될 수 있습니다.
- 낮/저녁/밤에서 불투명 사각 배경이나 잘린 이미지가 없는지 확인합니다.

## 0.11.0 밝기 확인 (실행 대기)

1. 100/80/60% 변경 시 미리보기와 홈 배경이 어두워지고 휴대폰 화면 밝기 설정은 유지되는지 확인합니다.
2. 앱 재실행 및 빠른 모드 변경 후 밝기가 유지되는지 확인합니다. 밝기만 변경하면 차량 위치가 초기화되지 않아야 합니다.
3. 홈 화면에서 10초 이상 실행 후 진단에 해당 측정 밝기가 나타나는지 확인합니다.

## 0.12.0 통합 확장 (실행 대기)

1. 기존 버전에서 업데이트하고 기존 장면/날씨/밝기/속도/프레임 설정이 유지되는지 확인합니다.
2. 도로4종 × 시간대3종을 확인합니다. 해안선/숲/고속도로 안내판이 도로와 분리되고 차량 주행이 유지되는지 확인합니다.
3. 차량 그룹4개·색상3개를 바꾸고 긴 순환 뒤에도 선택한 종류만 나타나는지 확인합니다. 차량 수 변경도 확인합니다.
4. 맑음/비2종/눈/안개를 바꿉니다. 눈에서 비가 사라지고 안개에서 눈이 사라지는지, 화면 꺼짐/숨김 후 정상 재개하는지 확인합니다.
5. 낮→밤 전환4초와 도중 저녁 재선택을 확인합니다. 자동 시간대도 같은 전환이며 숨김 시간은 진행하지 않습니다. 도로 전환은 즉시 반영됩니다.
6. 빠른 모드 변경·앱 재실행 후 새 설정이 유지되는지, 실제 진단에 도로/종류/색상이 기록되는지 확인합니다.
7. 동일 기기/밝기/주행 조합에서60초 이상 진단 및 메모리 수집 후 비교합니다. 프레임 제출 평균은 표시FPS/전력 측정이 아닙니다. 도로 변경 반복 시 충돌/이미지 누락 여부도 확인합니다.

## 0.13.0 프리셋 확인 (실행 대기)

1. 서로 다른 도로/차량/색상/시간대/날씨/밝기/밀도/속도/프레임/자동 시간대/절전 연동 조합 두 개를 이름 붙여 저장합니다.
2. 값을 바꾼 뒤 각각 불러오고11개 항목·미리보기·홈 배경 반영을 확인합니다. 자동 시간대는 현재 현지 시각을 따릅니다.
3. 같은 이름으로 저장하여 취소 시 기존 내용 유지, 덮어쓰기 시 새 값 복원을 확인합니다.
4. 앱 종료/재실행 후 목록과 설정이 유지되는지 확인합니다. 빈 이름/32자 초과/11번째 저장 제한을 확인합니다.
5. 삭제 확인/취소를 확인하고 현재 배경 설정은 바뀌지 않는지 확인합니다. 모두 삭제한 빈 목록 안내를 확인합니다.

## 0.14.0 아트 확인 (실행 대기)

1. 도심·해안·산길·고속도로에서 소품이 정상 표시되고 차량 주행 차선을 가리지 않는지 확인합니다.
2. 낮/저녁/밤 및 전환 도중 형태가 갑자기 움직이거나 소품이 누락되는지 확인합니다. 먼 소품은 픽셀 축소로 디테일이 생략될 수 있습니다.
3. 차량6종/팔레트3개·프리셋 복원·날씨/밝기가 기존처럼 작동하는지 확인합니다.
4. 도로를 반복 변경하고 화면 꺼짐/복귀 시 이미지 누락/충돌 여부를 확인합니다.

## 0.15.0 풍경 (실행 대기)

1. 맵4종에서20초 이상 구름/조명/해안 잔물결 등 느린 변화를 확인합니다. 낮에는 조명이 약해집니다.
2. 풍경 꺼짐에서 추가 움직임이 사라지고 차량/날씨는 유지되는지 확인합니다. 화면 꺼짐/가려짐 후 복귀도 확인합니다.
3. 켬/꺼짐 프리셋 저장/복원, 기존 프리셋 복원(기본 켬), 앱 재시작 선택 유지와 진단 표시를 확인합니다.
4. 동일 조건의 진단으로 추가 부하를 비교합니다. 실제 표시FPS/배터리 측정과 구분합니다.

## 0.16.0 구도 확인 (실행 대기)

1. 전체 구도가 이전과 같고 위치 선택이 비활성인지 확인합니다.
2. 차량 중심에서 왼쪽/중앙/오른쪽 위치와 픽셀 선명도를 확인합니다. 가장자리 잘림은 의도한 동작입니다.
3. 미리보기/홈 배경 반영과 구도 변경 시 차량 위치 유지, 날씨/풍경/밝기 적용을 확인합니다.
4. 새 구도를 프리셋 저장/복원, 구버전 프리셋 기본 구도 복원, 앱 재실행 및 빠른 모드에서 설정 유지를 확인합니다.
5. 다른 화면 비율/가로모드에서 빈 옆 공간이나 이미지 누락이 없는지 확인합니다. 상단 하늘 여백 또는 크롭은 하단 정렬에 따른 기존 방식입니다.

## 0.17.0 통합 편의성 (실행 대기)

1. 구역 접기/펼치기·스크롤 및 모든 설정 변경 확인. 추천3종 적용 후 전체 설정과 기존 저장 목록 유지 확인.
2. 미리보기 누르기→전체 화면→뒤로/돌아가기, 앱 백그라운드·화면 꺼짐·회전에서 정상 재개 및 충돌 여부 확인.
3. 이름 변경/중복 거절/빈 이름/취소 확인. JSON 내보내기 후 다른 이름으로 바꾸거나 저장항목을 지우고 가져와 전체 값 복원 확인.
4. 중복/손상/범위초과/10개 초과/128KB 초과 파일은 거절하고 기존 프리셋/설정 유지 확인. 파일 선택 취소·빈 목록 내보내기 확인.
5. 설정 초기화 취소/확인 후 기본값과 저장 프리셋 유지 확인. 파일 저장 실패시 성공 메시지가 없으며 부분 파일이 남을 수 있습니다.

## 0.18.0 시안/이벤트 통합 (실행 대기)

1. 기존 설정으로 업데이트 후 값/저장 목록 유지 확인. 추천→노을 도심·시안 스타일을 선택해 새 건물/차량/따뜻한 조명/반사를 확인합니다. 추천은30fps이며 이전60fps 선택을 바꿉니다.
2.4개 맵×3시간대 및 눈/안개/밝기/확대 구도를 확인합니다. 도로 변경/전환에서 이미지 누락/잔상/차량 차선 이탈이 없는지 확인합니다.
3. 이벤트 켬/자주로 최초5초 후 나타나는 전철/배/새/서비스밴을 확인합니다.10초간 나타나고24초간격 반복. 이벤트만끄기/풍경만끄기를 각각 확인하며 주행은 유지되어야 합니다.
4. 화면꺼짐/앱가려짐/진단창에서 애니메이션 정지·복귀 및 이벤트시간 폭주 없음 확인.
5.24대와12대를 동일 조건으로 비교하며 진단 기록/부하를 확인합니다. 차량 간격/방향/순환도 확인. 추가 부하가 높으면12대/30fps를 선택할 수 있습니다.
6. 새 이벤트값/24대 프리셋 저장/불러오기/JSON 백업 및 구버전 프리셋 기본 이벤트 켬·보통 복원을 확인합니다.
