# 픽셀 차량 라이브 배경화면 구상

날짜: 2026-10-06

사용자 목표: 픽셀 디자인으로 실제 차량들이 도로를 무한히 주행하는 Android 라이브 배경화면. 퀄리티별 난이도 평가와 고퀄리티 예시 이미지 요청.

현재 단계: 아이디어 및 이미지 시안. 앱 소스 구현, 빌드, 실기기 검증은 아직 수행하지 않았습니다.

2026-10-06 갱신: 1차 화면 구성과 제작 규격은 [설계 문서](PIXEL_TRAFFIC_DESIGN.md)에 정리했습니다. 초기 한 방향 도로 구상을 사용자에게 제안한 양방향 도로로 구체화했습니다. 현재 결정은 설계 문서를 우선합니다.

시안 방향: 세로 화면, 비 온 뒤 저녁 도심, 위에서 비스듬히 내려다보는 구도, 세단/SUV/버스/배송 차량, 전조등과 후미등, 젖은 노면 반사. 생성 이미지는 분위기 참고용이며 바로 사용할 스프라이트나 애니메이션은 아닙니다.

구현 방향: Android WallpaperService와 Canvas 또는 OpenGL 렌더링. 차량은 화면 밖에서 생성·회수하여 무한 교통 흐름을 구성합니다. 첫 버전은 한 방향 고정 도로와 제한된 차량 종류를 사용하고 교차로·차선 변경은 이후 검토합니다. 기본 루팅은 필요 없습니다.

난이도: 단순 직선 도로 및 몇 종류 차량은 낮음~중간, 상세 차량 및 그림자/조명은 중간~높음, 교차로·날씨·시간 변화 및 고급 픽셀아트는 높음, 실제 차종별 여러 방향 스프라이트와 복잡한 교통 시뮬레이션은 매우 높음. 일정은 아트 범위와 기능 합의 전 확정하지 않습니다.

검증 계획: 홈/잠금화면 표시, 화면 꺼짐 및 비가시 상태 렌더링 중단, 프레임 안정성, 장시간 배터리·발열, 해상도/화면 비율, 차량 흐름의 자연스러움. 현재 실행한 검증은 없습니다.

다음 결정: 실제 차종 재현 여부, 카메라 구도, 시간대와 날씨, 첫 버전 기능 범위.

추가 시안 요청: 사용자가 예시 이미지 한 장을 요청하여 도트가 뚜렷한 16비트 스타일, 제한된 색상, 세로형 야간 도로와 여러 차량을 기준으로 새 이미지 생성을 요청했습니다. 첫 시안의 부드러운 일러스트 느낌을 줄이고 픽셀 격자가 보이는 방향으로 조정했습니다. 이미지는 채팅 출력으로 제공하며 앱 구현은 아닙니다.
