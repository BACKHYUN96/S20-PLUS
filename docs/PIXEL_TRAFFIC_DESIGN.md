# 픽셀 차량 라이브 배경화면 — 1차 화면 설계

작성: 2026-10-06. 단계 1의 제작 기준입니다. 사용자 변경 요청에 따라 조정할 수 있습니다. 앱·완성 아트는 아직 구현하지 않았습니다.

## 장면과 분위기

- 세로 화면, 고정된 높은 시점에서 도심 대로를 내려다봅니다. 엄밀한 등각 투영 대신 원근이 있는 3/4 구도를 사용합니다.
- 비가 그친 저녁입니다. 짙은 남색·보라색 배경과 노란 전조등, 빨간 후미등으로 대비를 만듭니다.
- 왕복 4차선(방향별 2차선), 직선 도로로 시작합니다. 중앙분리대로 진행 방향을 명확하게 구분합니다.
- 위쪽 먼 지점에서 내려오는 차량은 전면, 아래에서 멀어지는 차량은 후면이 보입니다. 카메라는 움직이지 않습니다.
- 생성 시안은 분위기 참고입니다. 차선 방향과 차량 크기·원근은 아래 규격에 맞춰 다시 제작합니다. 시안을 통째로 움직이는 방식은 사용하지 않습니다.

## 화면 배치

기준 논리 화면: 360×800px. 원점은 왼쪽 위, 좌표는 논리 픽셀입니다.

| 영역 | 범위 | 구성 |
| --- | --- | --- |
| 상단 | y=0~180 | 어두운 하늘, 먼 산, 작은 도시 불빛. 아이콘을 위해 밝은 효과와 차량을 배제 |
| 중경 | y=180~340 | 먼 건물, 도로 진입점, 단순한 창문 불빛 |
| 주 장면 | y=340~720 | 도로, 이동 차량, 인도와 나무, 양옆 건물 |
| 하단 | y=720~800 | 도로가 화면 밖으로 이어짐. 런처 독과 겹치므로 밝은 효과를 절제 |

도로의 위쪽 양 끝은 (190,260), (270,260), 아래쪽 양 끝은 (20,800), (350,800)입니다. 차선과 중앙분리대는 이 사다리꼴 내부에 배치합니다. 왼쪽 두 차선은 화면 아래 방향, 오른쪽 두 차선은 화면 위 방향입니다.

상단 여백은 읽기 쉬움을 위한 설계이며 런처마다 아이콘 배치가 다릅니다. 화면의 중앙에도 아이콘이 놓일 수 있으므로 차량 불빛은 과도하게 밝게 만들지 않습니다.

## 차량과 이동

- 차량 6종: 소형 해치백, 일반 세단, SUV, 택시형 세단, 파란 시내버스, 흰 배송 트럭.
- 실제 차량의 비례와 실루엣을 참고하되 첫 버전은 특정 제조사·모델·로고를 재현하지 않습니다. 실제 차종별 재현은 사용자와 범위를 정한 뒤 추가합니다.
- 종별 전면/후면 두 방향, 총 12개 기본 스프라이트. 색상 변형은 차체 영역만 바꿉니다.
- 가까운 지점 기준 크기: 승용차 약 24×40px, SUV 28×44px, 버스 32×72px, 트럭 30×60px. 이는 이미지 외곽 기준이며 차선 폭과 맞춰 최종 조정합니다.
- 먼 곳에서는 차량을 작게 표시하고 접근할수록 확대합니다. 차선 진행 방향에 맞춘 고정 기울기의 그림을 사용하고 매 프레임 회전하지 않습니다.
- 동시에 보이는 차량은 초기 목표 8~12대. 같은 차선에서는 추월하지 않고 앞차 간격을 유지합니다. 버스와 트럭은 승용차보다 느리게 설정합니다.
- 화면 밖에서 생성·회수하여 차량이 갑자기 나타나거나 사라지지 않게 합니다. 시간 기반 이동을 사용하여 프레임 속도가 바뀌어도 주행 속도를 유지합니다.
- 첫 버전은 차선 변경·신호 교차로·충돌·보행자 이동을 넣지 않습니다. 바닥 횡단보도도 첫 버전에서 제외하여 정지하지 않는 교통과 모순을 피합니다.

## 아트와 레이어

도트의 기준 크기를 통일하고 차량·배경에 같은 팔레트를 사용합니다. 기본 장면은 약 48색을 목표로 하며, 조명 합성으로 늘어나는 색은 허용합니다. 선과 명암은 도트로 표현하고 부드러운 사진풍 질감은 피합니다.

렌더링 순서:

1. 하늘·산·먼 도시와 고정 건물.
2. 도로·인도·차선·중앙분리대.
3. 차량별 노면 반사와 그림자.
4. 차량 본체. 먼 차량부터 가까운 차량 순으로 그립니다.
5. 차량 전조등·후미등 및 작은 발광 효과.
6. 전경 나무·가로등. 도로와 겹치는 부분만 차량을 가립니다.

필요한 이미지: 고정 장면 배경, 차량 12개와 차체 색상 마스크, 차량별 그림자/조명 마스크, 전경 가림 레이어. 모두 투명 PNG를 기본으로 합니다. 배경 그림에 차량을 포함하지 않습니다. 반사는 각 차량 위치를 따라 이동하는 별도 효과입니다.

내부 도트 화면을 가로 360px 기준으로 렌더링하고 최근접 보간으로 확대합니다. 높이는 실제 화면 비율에 맞춥니다. 기준보다 긴 화면은 하늘을 확장하고, 짧은 화면은 상단 하늘을 줄여 주요 도로를 보존합니다. 원근 확대에서 도트 크기가 달라질 수 있으므로 이미지가 흔들리지 않도록 그리기 좌표와 표시 크기를 픽셀 단위로 정렬합니다. 이 방식의 실기기 화질은 후속 검증 대상입니다.

## 첫 버전 범위와 확인 기준

- 완료 목표: 도심 한 장면, 차량 6종, 양방향 무한 주행, 차량 조명·짧은 노면 반사.
- 비 내리는 애니메이션, 시간대 변화, 도로 선택, 특정 차종과 복잡한 교통은 후속 버전입니다.
- 기본 30fps를 목표로 하지만 배터리·발열·프레임 유지 성능은 아직 측정하지 않았습니다.
- 장면 검수: 양방향 차선과 차량 방향이 맞음, 차량/배경 도트 크기가 일관됨, 앞차를 통과하지 않음, 생성·회수 순간이 보이지 않음, 전경 가림이 자연스러움, 아이콘을 읽을 수 있음.
- 2단계에서 WallpaperService 기본 프로젝트와 임시 도형 장면을 먼저 구성합니다. 완성 아트 적용은 4단계이며, 이번 설계 완료가 아트 제작 완료를 뜻하지 않습니다.
