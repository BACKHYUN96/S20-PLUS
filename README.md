# S20+

Unity 전환 프로젝트와 PC 자동 검사는 [Unity 안내](pixel-traffic-unity/README.md) 및 [자동 검사 설정](docs/UNITY_AUTOMATION.md)을 참조합니다. Unity는 별도 Activity 시제품이며 기존 Android 라이브 배경화면 이전은 진행 중입니다.

루팅된 Samsung Galaxy S20+ 관련 앱과 도구의 개발 작업 공간입니다.

현재 전달 버전은 **픽셀 트래픽 0.29.0**입니다. 같은 차종·같은 거리의 차량 크기를 차선 공통으로 맞추고, 반대 방향 차량에도 진행 방향의 전조등 비춤을 추가했습니다. 후미등 가시성도 보강했습니다. 작업 재개 시 [최신 상태](docs/STATUS.md)와 [패치 작업 안내](docs/PATCH_GUIDE.md)를 먼저 읽고 관련 파일·검사만 선택합니다. 이전 버전 기록은 아래에 보존합니다.

새 채팅은 [인수인계](docs/HANDOFF.md)와 [빌드·서명 복원](docs/BUILD_RESTORE.md)에서 시작합니다.

## 작업을 이어가기 전에

1. [AGENTS.md](AGENTS.md)의 작업 및 기록 규칙을 읽습니다.
2. [현재 상태](docs/STATUS.md)에서 확인된 사실과 다음 할 일을 확인합니다.
3. [작업 이력](docs/WORK_LOG.md)에서 변경 이유, 검증 결과, 미해결 사항을 확인합니다.
4. 실제 파일과 Git 상태를 확인합니다. 문서에 적힌 계획을 완료된 구현으로 간주하지 않습니다.

현재 저장소에는 픽셀 트래픽 기본 앱 소스와 빌드 설정이 있습니다. 레드존 APK와 측정 로그 분석 결과를 문서로 기록했으며, 원본 프로젝트는 확보하지 못했습니다.

새로운 앱을 추가하면 앱별 설명, 설치·실행 방법, 환경 요구 사항을 함께 기록합니다. 중요한 작업마다 현재 상태와 작업 이력을 갱신하여 다른 개발자나 새 GPT 채팅에서도 이어갈 수 있도록 합니다.

화면 설계: [픽셀 차량 라이브 배경화면 화면 설계](docs/PIXEL_TRAFFIC_DESIGN.md). 단계 1 설계를 기준으로 단계 2 기본 앱을 구현했습니다.

진행 갱신: [픽셀 트래픽 앱](pixel-traffic/README.md) 0.2.0에 미리보기·배경화면 설정 연결과 양방향 무한 차량 주행을 구현했습니다. 그림은 임시이며 완성 아트는 다음 단계입니다. 앱별 README에서 빌드/설치 방법과 실기기 확인 항목을 읽습니다.
