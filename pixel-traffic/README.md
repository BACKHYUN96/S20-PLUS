# 픽셀 트래픽 — 0.29.0

Android 라이브 배경화면입니다. 4차선에서 6종 차량이 무한 주행합니다. 0.19.0에는 고밀도 전용 노을 도심 배경·투명 차량 아틀라스와 GPU Canvas 합성을 추가했습니다. 기존 4개 도로, 낮/저녁/밤, 날씨, 차량·구도 설정도 지원합니다. 루팅·인터넷 권한은 필요하지 않습니다. 참조 시안과 동일한 표현 수준이나 실기기 성능은 아직 확인하지 않았습니다.

## 설치

APK를 다음 폴더에 다운로드한 뒤 노트북 PowerShell에서 실행합니다.

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r "C:\Users\LNS HRD\Desktop\블랙\AI\새 폴더\pixel-traffic-0.29.0-debug.apk"
```

`Success` 후 앱을 열거나 배경화면을 다시 선택합니다.

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" shell am start -n com.s20plus.pixeltraffic/.MainActivity
```

같은 서명의 기존 버전은 업데이트로 설치하며 설정을 유지합니다. 홈/잠금화면 적용 선택은 Android의 기기 설정에 따릅니다.

## 교통 신호와 정차·순차 출발 (0.26.0)

**전용 아트 도심**에서 **차량 · 종류와 색상 → 교통 신호 · 전용 도심**을 켭니다. 업데이트와 구버전 프리셋에는 기본 켬으로 적용됩니다. 두 방향이 같은 횡단보도 신호를 따르며 **초록14초 → 노랑3초 → 빨강9초**를 반복합니다. 화면이 가려지면 주행과 신호 시간도 함께 멈춥니다.

차량은 앞차와 실제 차체 길이에 맞춰 미리 감속하고, 차체 앞끝을 횡단보도 바깥에 정차시킵니다. 큰 버스·트럭도 차선/크기 계산을 유지합니다. 노랑으로 바뀔 때 편안하게 멈출 수 없는 가까운 차량은 그대로 통과하고, 정지선 뒤 차량은 멈춥니다. 초록에는 앞차부터 반응시간을 두고 가속합니다. 밀도가 높으면 여유 간격에 맞춰 주행이 느려집니다. 차량 수를 바꾸면 기존 동작처럼 차량 배열을 다시 만들고 신호는 초록에서 시작합니다. 날씨·시간대·구도·밝기를 바꿀 때는 위치와 신호 진행을 보존합니다.

실제 감속/정차 때 보이는 **뒤쪽 브레이크등과 젖은 도로의 붉은 반사**를 밝힙니다. 앞쪽 헤드라이트는 붉게 바꾸지 않습니다. 정차 차량의 바퀴 물보라는 멈추고 비·눈·풍경 이벤트는 계속 움직입니다. 신호를 끄면 신호등이 사라지고 대기차가 가속해 자유 주행으로 복귀합니다. 다른 도로와 기본 도심은 기존 주행을 사용합니다. 신호 선택은 저장 프리셋/JSON에 포함하며, 빠른 성능 설정은 이 선택을 유지합니다.

최근 주행 진단에 신호 색/자유 주행과 대기 대수를 표시합니다. 새 권한·PNG 자산은 추가하지 않았습니다. 물리적 차량 속도/도로 교통법규 시뮬레이터나 보행자·교차로 충돌 모델은 아닙니다.

Android 빌드/Lint와 APK code26/version0.26.0·기존 v2서명/PNG13개 일치를 확인했습니다. **실기기 확인 대기**: S20+/S26 Ultra에서 신호·대기/출발, 끄기/켜기·프리셋 저장/복원과 숨김/복귀. 실제 표시FPS·전력/발열은 미측정입니다.

## 눈·안개 전용 도심과 배경 캐시 (0.25.0)

**전용 도심**을 켠 상태에서 **날씨 → 눈/안개**, **장면 시간대 → 낮/저녁/밤**을 선택합니다. 눈은 지붕·나무·보도의 적설과 제설된 차선/타이어 자국을 표시하고, 가로등 근처 눈송이는 따뜻하게 빛납니다. 안개는 먼 산·도시·강부터 흐려지며 가까운 차선은 선명하게 유지합니다. 가로등/차량 불빛은 부드럽게 번지고 먼 차량·열차 이벤트는 은은하게 흐려집니다.

첫 선택은 즉시 표시하고 이후 **약4초의 활성 재생 시간** 동안 날씨/시간대를 전환합니다. 전환 중 재선택해도 현재 화면에서 이어집니다. 눈송이는 앞/뒤 레이어로 나누고 눈을 끄면 배경과 함께 사라집니다. 맑음·약한비·강한비의 마른/젖은 도로와 기존 설정/프리셋·차량 크기/차선은 유지합니다. 실제 기상/위치 동기화나 시간에 따라 눈이 물리적으로 쌓이는 모델은 없습니다.

배경12장을 전부 상시 로드하지 않습니다. 기본 대체 그림1장과 현재/전환에 필요한 시간대·날씨 그림만 로드하고 전환이 끝나면 쓰지 않는 그림을 해제합니다. 노을 눈/안개에서 배경 캐시는2장(약12MiB 픽셀), 낮/밤은3장(약18MiB)이며 이전6장 상시 캐시는 약36MiB였습니다. 짧은 간격으로 시간대/날씨를 여러 번 바꾸면 전환에 필요한 최대12장(약72MiB)이 일시적으로 남을 수 있습니다. 이는 이미지 픽셀 계산치이며 실제 프로세스/GPU 메모리나 전력 측정이 아닙니다. 이미지 로드는 설정 선택 시 수행하며 update/draw에서 디코딩하지 않습니다.

최근 주행 진단에 **배경 캐시 장수**와 날씨 아트 대체 여부를 표시합니다. 새 배경이 누락/손상·크기 불일치/메모리 부족으로 로드되지 않으면 기존 마른/젖은 그림과 눈 효과로 대체합니다. 정상 선택/전환 캐시는 반복 설정에서도 재사용하고 사용이 끝난 그림과 Scene 종료 시 소유 그림을 해제합니다.

검증: 배경12장의 중앙선96/횡단보도72표본, 시간대·날씨 독립 색혼합/재선택·초기 표시, 실제24대 위치·자세, 캐시 재사용/전환 종료 해제·프레임 중 디코딩 없음/실패 대체·눈 레이어, 기존 차체/효과와99합성 검사를 통과했습니다. Android 빌드/Lint·APK 서명/code25·version0.25.0/포함PNG13개 소스 일치 확인도 완료했습니다. 실기기에서 시간대×눈/안개6조합, 맑음↔눈↔안개 전환·차선/크기, 숨김·복귀와 메모리/성능을 확인합니다.

## 날씨별 마른·젖은 노면 (0.24.0)

**전용 도심**을 켜고 날씨를 선택합니다. 맑음은 마른 아스팔트·보도, 약한 비는 부분적으로 젖은 노면, 강한 비는 기존 젖은 노면을 표시합니다. 낮·노을·밤을 모두 지원합니다. 첫 화면은 선택된 날씨를 즉시 적용하고 이후 변경은 약4초의 **배경화면 활성 시간** 동안 부드럽게 전환합니다. 화면이 가려지면 전환도 멈췄다가 이어집니다.

비를 끄면 빗줄기는 즉시 멈추고 노면 반사·바퀴 물보라는 마르는 동안 서서히 사라집니다. 마른 도로에도 차량 램프·작은 빛 번짐과 그림자는 유지합니다. 0.24.0의 눈은 마른 기본 노면 위 기존 눈 효과, 안개는 약간 축축한 노면 위 기존 안개 효과를 사용했고(0.25.0에서 전용 배경 추가), 눈/안개에는 바퀴 물보라를 표시하지 않습니다. 실제 기상·위치 동기화는 없습니다.

진단에 **노면: 마름/젖음/전환·습윤 · 젖음 %**를 추가했습니다. 마른 아트가 없거나 손상된 경우 사용 가능한 같은 시간대의 젖은 그림으로 대체합니다. 차체 크기·차선·주행과 저장 설정은 유지합니다.

0.24.0의 마른 배경3장 상시 캐시 추가 픽셀 데이터는 약18MiB(계산치)입니다. 하늘·강은 원래 그림을 유지하고 도로 지평선 아래만 마른 그림을 합성합니다. 전체 프레임 CPU 비트맵은 생성하지 않습니다. 낮 마른 생성본은842×1869, 나머지 배경은841×1870이며 같은540×1200 구도로 표시하고 독립 차선 표본을 확인했습니다.

검증: 중앙선48/횡단보도36표본, 시간대·날씨 동시 색혼합/4초·재선택, 실제 차량 위치·자세/캐시·대체·해제, 기존 차체·효과 및99합성 검사를 통과했습니다. Android 빌드/Lint·APK 서명/버전·7PNG 포함 확인도 완료했습니다. S20+/S26 Ultra에서 날씨 변경·시간대 동시 변경·숨김/복귀와 추가 부하는 설치 후 확인합니다.

## 전용 도심 낮·노을·밤 (0.23.0)

전용 도심을 켠 상태에서 **장면 시간대 → 낮/저녁/밤**을 선택하면 같은 도로 구도의 세 전용 아트를 사용합니다. 낮은 밝은 하늘·외벽과 약한 조명, 밤은 별이 있는 하늘·따뜻한 창문/가로등과 강한 차량 반사를 표현합니다. 기존 노을과 차량PNG/차선·크기 보정은 유지합니다.

**시간대 자동 전환**도 전용 도심에 적용됩니다. 휴대폰 현지 시각 기준06:00~16:59 낮,17:00~19:59 노을,20:00~05:59 밤이며 실제 일출/일몰이나 위치 동기화는 아닙니다. 처음 전용 장면을 열면 선택한 시간대가 바로 표시되고 이후 변경은4초의 활성 재생 시간에 부드럽게 전환합니다. 도중 재선택해도 현재 혼합 상태에서 이어집니다. 화면이 가려지거나 꺼지면 전환도 멈추고 차량 위치/크기를 초기화하지 않습니다.

기존 설정·프리셋의 시간대 값을 그대로 사용합니다. ‘전용 아트 · 비 오는 노을 도심’ 추천은 계속 노을을 선택하므로 다른 시간대나 자동 모드는 직접 선택합니다. 컬러풀/파스텔은 기존 차량을 쓰고 다른 도로는 기본 아트입니다. 0.23.0 당시 모든 시간대의 노면은 젖은 아트였으며, 0.24.0에서 마른 노면을 추가했습니다.

0.23.0은 같은 크기841×1870의 낮/밤 PNG를 추가로 상시 캐시했습니다. 0.25.0부터는 필요한 그림만 캐시합니다. 두 장의 ARGB 픽셀 데이터는 계산상 약12MiB 추가이며 실제 프로세스/GPU 메모리는 별도입니다. 자산 누락·손상/크기 불일치/선택 자산 로드 실패는 전용 노을로 대체하고 진단에 표시합니다. 전용 기본 노을까지 로드할 수 없으면 기존 장면으로 돌아갑니다.

독립 원본 중앙선24표본/횡단보도18표본, 실제4초 혼합·초기 선택/재선택/차량 자세·캐시/오류·해제, 기존 차선·크기/효과 및 세시간대99합성, Android 빌드/Lint·APK 서명/버전/4PNG 일치 검사를 통과했습니다. Android UI·자동 시각 변경·실제 기기 성능은 설치 후 확인합니다.

## 조명·노면 반사·비 효과 (0.22.0)

전용 도심에서 차량별 실제 램프 위치를 측정해 헤드라이트/후미등과 노면 반사를 맞췄습니다. 거리·날씨에 따라 반사 길이/밝기가 달라지고, 가로등을 지날 때 따뜻한 빛이 차체 윤곽 안에서 부드럽게 변합니다. 기존 PNG에 그려진 정적 반사도 유지합니다.

비는 먼/가까운 레이어로 나눠 크기와 밝기를 다르게 표현하며 같은 노면 위치에 착지합니다. 0.22.0은 비가 올 때만 바퀴 물보라가 생겼고 강한 비에서 더 진해졌습니다. 0.24.0부터는 비가 그친 뒤 마르는 동안에도 물보라가 남습니다. 추가 효과는 활성 재생 시간에만 진행하며 물보라 주기는 선택한 차량 속도에 연동합니다. 전용 도심 설정을 유지한 채 업데이트하면 반영되고, 새로운 권한이나 설정 선택은 없습니다. 기존4맵의 기본 아트 효과는 이번 변경 대상이 아닙니다.

효과 연속성/소스 램프·마스크/젖음·마름/레이어·속도·시간·해제 검사와 기존 차선·크기/33합성 및 Android 빌드/Lint·서명·버전 검사를 통과했습니다. 실제 S20+/S26 Ultra의 새 표현과 추가 부하는 설치 후 확인합니다. 기존0.21.0 크기 보정은 유지합니다.

## 이동 중 차량 크기 안정화 (0.21.0)

도로 굴곡에서 버스가 갑자기 작아지던 위치별 반복 축소를 제거했습니다. 차체 폭은 노면의 깊이에 따라 일정하게 증가하고 실제 그림의 가로·세로 비율을 유지합니다. 차체 전체 길이를 따라 기울기를 계산하여 긴 차량도 차선 안에 들어갑니다. 차체·접지 그림자·조명 반사가 같은 크기와 기울기를 공유합니다. 기존 전용 도심 설정을 유지한 채 업데이트합니다.

크기·길이·기울기 연속성, 전체 차체 차선 유지, 실제 Scene 팔레트 전환/차량 픽셀, 33개 합성 조합과 Android 빌드/Lint·서명·버전 검사를 통과했습니다. S20+/S26 Ultra에서 이동 중 표현 확인은 설치 후 진행합니다.

개발자는 [패치 작업 안내](../docs/PATCH_GUIDE.md)에서 관련 파일·검사를 고릅니다. 이번 변경의 최종 데스크톱 검사는 `tools/check-patch.sh cinematic`이며 기하 검사를 포함하므로 같은 입력으로 `geometry`를 중복 실행할 필요가 없습니다.

## 차선 정렬과 차량 비율 보정 (0.20.0 당시 변경)

0.19.0 적용 스크린샷에서 발견한 작은 차체·차선 이탈·차량 조각 혼입을 수정했습니다. 전용 도심 설정을 유지한 채 업데이트하면 반영됩니다.

- 배경의 외곽 실선2개/흰 점선2개/노란 중앙선 중심을 각각 실측했습니다. 그림의 차선 폭이 서로 달라 기존 균등4분할을 제거하고 다섯 경계 사이 중심을 따라 주행합니다. 곡선과 기울기는 부드럽게 연결하며 화면 밖에서도 이어집니다.
- 차량 아틀라스의 행 간격이 균등하지 않아 고정362px 높이로 자를 때 다음 차량 지붕이 섞였습니다. 각 열의 실제 투명 간격으로 세 행을 분리하여 완전한 차체를 사용합니다. 폭·높이 중 작은 쪽에 맞추는 축소도 제거하고 차선 폭에 맞춘 차체 폭과 원본 비율로 크기를 정합니다.
- 승용차는 차선 폭의60~65%, 대형차는72%를 목표로 하며 먼 쪽 차선이 좁아지는 구간에서는 차체 전체가 들어가도록 크기를 제한합니다. 이미지 하단을 노면 접지점에 맞추고 가까운 차량의 원근 크기와 이동 속도를 자연스럽게 키웠습니다. 주행 모델의1200 고리/150 최소 간격은 유지합니다.
- 반사·램프·부드러운 접지 그림자를 실제 차체 크기와 동일한 위치/기울기에 맞췄습니다. 화면 아래에서는 차체 전체가 나간 후 표시를 끝냅니다. 원본 PNG와 설정·서명은 유지합니다.
- Android 빌드/Lint/서명·버전 검사, 독립 실측/차폭/차선/접지/최소 간격28,704개 자세, 실제 아틀라스12종·픽셀 차선120개 자세·장면33조합 검사 통과. 여러 진행 시점의 데스크톱 합성을 확인했습니다. 새 버전 실기기 표현/성능은 적용 후 확인합니다.

## 전용 아트와 GPU 합성 (0.19.0 도입)

- **추천 프리셋 → 전용 아트 · 비 오는 노을 도심**을 선택하면 새 장면을 바로 봅니다. 도심/고정 노을/강한 비/24대/기본 차량 색상/전체 구도/30fps/속도1배/밝기100%/풍경·이벤트 켬입니다. 설정의 장면 구역에서 **전용 아트 도심**을 직접 켤 수도 있습니다. 업데이트만 하면 기존 설정이 유지되므로 새 모드는 자동으로 켜지지 않습니다.
- 건물·상점·가로수·젖은 도로·먼 도시·수면을 전용 PNG 배경으로 제작했습니다. 배경841×1870, 투명 차량 아틀라스1448×1086(4열×3행, 열362px·행은 실제 투명 간격으로 분리), 논리 구도540×1200입니다. 매 프레임 전체 이미지를 CPU 비트맵으로 만들지 않고 캐시된 배경·차량·반사·효과를 직접 Canvas에 그립니다.
- 실제 배경화면은 `lockHardwareCanvas()`로 GPU 합성을 요청합니다. 초기 하드웨어 연결이 지원되지 않으면 해당 Surface에서 소프트웨어로 표시합니다. 이미 하드웨어로 연결된 Surface의 일시 실패는 프레임을 건너뛰고 다시 시도합니다. 기본 아트도 같은 Surface의 GPU Canvas에 기존 픽셀 프레임을 표시하여 모드 전환 시 producer 교대를 피합니다. OpenGL ES 자체 렌더러를 작성한 것은 아닙니다.
- **0.19~0.22의 전용 배경은 노을 고정**이었습니다. 0.23.0부터 전용 도심도 낮·밤·자동 시간대를 적용합니다. 해안·산길·고속도로는 기존 아트를 사용합니다. 차량 색상 **기본**에서 새 차량 그림을 사용하며 컬러풀/파스텔은 기존 스프라이트입니다. 0.23.0까지는 맑음에도 젖은 노면을 유지했고, 0.24.0부터 전용 도심의 마른 노면을 지원합니다.
- 양방향 차량/종류 필터/수·속도, 반사, 비·눈·안개, 밝기, 확대 구도, 작은 교량 전철 이벤트를 연결했습니다. 풍경 추가 효과·이벤트는 스위치와 활성 시간 정책을 따르며, 화면 꺼짐/비가시 상태에서 함께 멈춥니다.
- 앱 미리보기/전체 화면 미리보기/시스템 미리보기/홈 배경에 연결하고 프리셋 저장·JSON 백업에 새 선택값을 포함했습니다. 구프리셋의 새 값은 꺼짐으로 복원합니다. 자산 읽기 실패 시 기존 장면으로 돌아갑니다.
- 진단의 **렌더링: GPU Canvas · 전용 아트**로 실제 하드웨어 Canvas 사용 여부를 확인합니다. 제출 FPS와 평균 그리기 시간은 GPU 완료·실제 표시 FPS나 전력 측정이 아닙니다. Android 빌드/Lint, 독립 계산11종, 기존 합성60조합과 전용 합성33조합·아틀라스 검사를 통과했습니다. 두 기기의 새 버전 표현과 성능은 사용자 적용 후 확인합니다.

자산·렌더러 설계와 검증 한계는 [전용 렌더러 기록](../docs/CINEMATIC_RENDERER.md), 재현 도구는 [cinematic-preview](tools/cinematic-preview/README.md)에 있습니다.

## 사용 편의성 패키지 (0.17.0)

- 설정 구역은 프리셋/빠른 설정/장면/차량/효과/주행/적용으로 접고 펼칩니다. 화면 재생성 시 초기 펼침 상태로 돌아갑니다.

## 설정

- 배경 밝기: 100/80/60%, 기본 100%. 장면 합성 후 검정 오버레이로 배경 그림만 어둡게 합니다. 화면의 하드웨어 밝기는 변경하지 않습니다. 미리보기/실제 배경화면에 자동 반영하고 빠른 모드에서도 보존합니다. 밝기 변경은 차량 위치를 초기화하지 않습니다.

- 장면 시간대: 낮/저녁/밤 수동 선택. 기본 저녁.
- 날씨: 맑음/약한 비/강한 비. 기본 맑음. 맑음은 빗방울만 끄며 비가 그친 도로의 반사는 유지합니다. 약한 비 28개, 강한 비 72개의 고정 입자와 도로 물 튀김을 사용합니다.
- 차량 수: 화면 밖까지 포함한 전체 4/8/12/24대. 기본 12대. 변경 시 교통 배치를 초기화합니다.
- 이동 속도: 0.5/1/1.5배. 기본 1배. 시간대/날씨/속도만 변경할 때는 차량 위치를 보존합니다.
- 프레임 제한: 15/30/60fps. 기본 30fps. 주행 속도와 프레임 제한은 별개이며 실제 달성 빈도는 기기 부하에 따릅니다.
- 휴대폰 절전 모드 연동: 기본 켬. 절전 중 최대 15fps, 해제하면 선택값으로 복귀합니다.
- 자동 저장 및 실행 중인 엔진 반영. 화면 꺼짐/비가시 상태에서는 차량과 비 모두 멈추고 복귀 때 시간을 초기화합니다.
- 시간대 자동 전환은 선택적으로 휴대폰의 현지 시계를 사용합니다. 날씨는 수동이며 기상 정보나 위치에 동기화하지 않습니다.

## 앱 안 실시간 미리보기

설정 화면 위에 360×800 장면 전체를 비율 유지하여 표시합니다. 장면·비·차량·속도 변경이 자동 반영됩니다. 미리보기는 별도 차량 시뮬레이션으로 15fps 실행하며 홈 배경화면의 프레임 설정과 차량 위치는 독립적입니다. 앱 비가시/일시중지/창 포커스 상실 시 멈추고 종료 시 자원을 해제합니다. 실제 배경화면 진단을 덮어쓰지 않습니다. Android UI 및 추가 전력은 실기기 확인 대기 중입니다.

## 최근 주행 진단

홈 화면에서 30초 이상 주행한 뒤 앱의 진단 버튼을 엽니다. 프레임 제출 평균, 그리기 시간, 상태 및 장면/날씨/차량 수/속도를 로컬로 기록합니다. 약 10초마다 및 중지 시 요약을 저장하며 미리보기 엔진은 실제 배경화면 기록을 덮어쓰지 않습니다.

앱을 열면 배경화면이 가려져 중지됨이 정상일 수 있습니다. 프레임 제출 평균은 실제 화면 표시 FPS·GPU 프레임 드롭·배터리 측정값이 아닙니다. [실기기 검증 절차](../docs/PIXEL_TRAFFIC_DEVICE_CHECKS.md)를 참고합니다. 0.6.0 사용자 기록에서는 제한 60fps에 제출 평균 59.9fps였으며, 0.8.0의 비 효과와 장시간 전력은 미검증입니다.

## 빌드

새 환경은 [인수인계](../docs/HANDOFF.md)와 [서명·빌드 복원](../docs/BUILD_RESTORE.md)을 먼저 읽습니다. 저장소의 `tools/build-cloud.py`는 기존 서명키·프록시/CA·실제 체크아웃 경로를 사용합니다. `tools/restore-debug-signing.py`는 별도 백업에서 기존 키만 복원하며 개인 키는 Git에 포함하지 않습니다.

JDK 17 이상(컴파일러 포함), Android SDK 35, Build Tools 35.0.0이 필요합니다. Gradle Wrapper 8.11.1과 Android Gradle Plugin 8.9.2를 고정했습니다. Android Studio에서 이 폴더를 열거나 `local.properties`에 SDK 위치를 지정합니다(커밋 제외).

```properties
sdk.dir=C:/Users/YOUR_NAME/AppData/Local/Android/Sdk
```

이 폴더에서 Windows:

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

Linux/macOS는 `./gradlew`를 사용합니다. 출력은 `app/build/outputs/apk/debug/app-debug.apk`입니다. 쓰기 제한 환경에서는 ANDROID_USER_HOME과 GRADLE_USER_HOME을 쓰기 가능한 경로로 지정합니다. 프록시 환경에서는 JVM의 http/https proxyHost/proxyPort와 정상 CA 신뢰가 필요하며 TLS 검증을 끄지 않습니다.

현재 클라우드의 도구는 `/workspace/toolchains`에 있습니다. JDK 경로 `/workspace/toolchains/jdk-21.0.8+9`, SDK 경로 `/workspace/toolchains/android-sdk`, 빌드 도우미 `/workspace/toolchains/run-gradle.py`. 새 환경에서 이 도구가 복원된다는 보장은 별도 확인해야 합니다.

## 자동 시간대와 빠른 모드

자동 전환은 기본 꺼짐으로 기존 수동 장면을 유지합니다. 켜면 휴대폰 현지 시간 기준 06:00~16:59 낮, 17:00~19:59 노을, 20:00~05:59 밤입니다. 실제 일출/일몰 계산이 아닙니다. 자동 모드에서는 수동 장면 선택을 비활성화하고, 끄면 저장된 수동 선택으로 돌아갑니다.

화면이 보일 때 최대 1분 간격과 화면 복귀 시 시간을 확인합니다. 시간/시간대 변경 방송도 반영합니다. 숨겨진 화면을 깨우는 알람이나 백그라운드 폴링은 사용하지 않습니다. 시간대 정책을 처음 도입한0.8.0은 즉시 전환이었고, 현재 기본/전용 도심은4초의 활성 재생 시간 동안 부드럽게 전환합니다.

빠른 모드: 절약 4대/15fps, 균형 8대/30fps, 부드럽게 12대/60fps. 모두 속도 1배/절전 연동 켬으로 저장하고 기존 장면·날씨·자동 시간대 설정은 유지합니다. 차량 수가 달라지면 배치를 새로 구성합니다. 이름은 설정 의도를 나타내며 실제 전력 절감량을 보장하지 않습니다.

## 실제 합성 경로의 데스크톱 시안

기존 아트 도구는 정적 레이어만 보므로 반사/비/전환/이벤트가 포함된 검토에는 [render-preview](tools/render-preview/README.md)를 사용합니다. 전체60조합 검사와 도로별 합성 PNG 출력 명령은 해당 문서에 있습니다. Java2D shim이며 Android 화면 검증을 대신하지 않습니다.
