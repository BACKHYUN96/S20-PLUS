# ABYSS v1.4.0 — 시안 재현을 위한 전용 화면

승인된 시안은 디자인 목표이며 앱 실행 캡처/검증 근거가 아니다. 앨범은 요청대로 작은 원형을 큰 전망창 뒤에 유지한다. 이 빌드는 다음 구현을 실제 플레이어에 연결한 비교용 빌드다.

| 시안 요소 | 구현 |
|---|---|
| 원경·가까운 지형 | 기존 원경 + 별도 transparent foreground.png, 서로 다른 카메라 drift |
| 전망창 중심 구도 | viewport에서 실제 조작부 높이를 뺀 나머지에 240~520 dp hero 배정 |
| 도구 단순화 | 출력 경로는 앱 내부 데이터/설정에 유지, A–B·선택·가사·즐겨찾기는 한 행 |
| 하단 아이콘 | 네이티브 버튼 위 전용 Canvas 아이콘과 라벨; 큰 글꼴에서 native fallback |
| 움직이는 해파리 | 8×16 mesh, bell 수축과 tail row 지연 변형, 재사용 vertex buffer |
| 앞쪽 물방울 | 터치를 통과시키는 전경 레이어, 외곽 중심 배치, radial 명암·원경 굴절 근사 |

고정 그림의 중앙에 UI를 붙인 화면을 애니메이션이라고 표시하지 않는다. 원경/지형은 2D 그림이고, 서로 다른 변환/mesh/입자 궤적으로 공간감을 만든다. 물방울은 실제 UI 픽셀의 광학 굴절을 캡처하는 3D 렌더러가 아니라 원경 texture와 하이라이트의 근사다. 해파리는 골격/유체 시뮬레이션이 아닌 sprite mesh다.

## 배치와 동작 보존

- 실제 ScrollView viewport와 조작부 measured height를 사용한다. 짧은 화면/큰 글꼴/오류 안내/A–B 확장에서는 최소 hero 이후 스크롤한다.
- 외부 테마에 artworkHeight가 명시되었으면 지정값을 보존한다.
- MainActivity의 source/state/intent 연결과 기존 decode/USB/PCM 코드는 유지한다.
- 원형 앨범 터치/확대/뒤로 가기, 몰입 탐색·A–B, 가사/즐겨찾기/파일 선택을 유지한다.
- 기존 USB Direct 강조 버튼의 넓은 반사 호 수정은 유지한다.

## Galaxy 비교 순서

1. 어비스와 기본 강도로 적용하고 세로 일반 글꼴에서 메인 화면을 캡처한다.
2. 시안과 전망창/곡명/탐색/재생 버튼/하단 메뉴의 상대 위치를 비교한다.
3. 해파리 bell과 tail이 같은 비율로만 확대되지 않고 서로 지연되어 움직이는지 확인한다.
4. 물방울은 UI보다 앞에 보이되 글자와 입력을 과하게 가리지 않는지 확인한다.
5. 큰 글꼴/가로/AB 펼침/긴 제목/표지 없음/연속 NEXT/오프닝 종료를 확인한다.
6. ORIGINAL/화현 복귀와 USB 실제 음악 재생을 확인한다.

이 환경에는 Android emulator system image/연결 기기가 없어 실제 화면을 렌더링해서 픽셀 비교하지 못했다. 단위 테스트는 mesh/배치 계산을 검증하며 실제 View 레이아웃, GPU 프레임/메모리/발열 검증을 대신하지 않는다. 설치 후 Galaxy의 캡처를 기준으로 추가 보정해야 한다. 시안과 모든 상황에서 완전히 동일하다는 주장은 하지 않는다.
