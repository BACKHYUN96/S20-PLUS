# ABYSS v1.6.0 — 전망창·구도·수중 조명 보정

사용자가 전달한 `Screen_Recording_20261019_191102.mp4`(약 7.17초, 1080×2340)를 시간대별 프레임으로 확인했다. 전망창이 작고 구형 컨트롤/기포가 상대적으로 커 보였으며, 중앙의 그물 형태 빛무늬가 두드러졌다. 이번 패치는 합의한 구도와 조명 단계다. 해파리/기포의 생체·부력 모션과 이미지 자산은 다음 집중 보정 대상으로 유지한다.

## 변경

- 기존 높이 계산은 `viewport - controls`만 사용해 창을 축소했다. 이제 자동 배치에서 콘텐츠 너비의 1.04배를 최소 hero 높이로 확보한다(240~520dp 범위). 짧은 화면/큰 글꼴/A–B 확장에서는 ScrollView로 접근한다. 조작부 전체를 한 화면에 맞추기 위해 전망창을 다시 줄이지 않는다.
- 기본 가로 여백 16dp에서 360~480dp 휴대폰의 창 지름은 계산상 화면 너비 약 85.6~87.7%다. 실제 기기 캡처 측정값은 아니다. 명시적 외부 테마 artworkHeight는 우선하며 가로 몰입 화면의 두 열 구성을 유지한다.
- 원형 앨범은 창 뒤에 겹치는 구성을 유지하고 창 대비 반지름을 0.35에서 0.28로 줄였다. 공통 geometry를 그림/터치/시작 연출 도착/표지 확대 시작점에 사용한다.
- 어비스 기본 재생 버튼은 72dp 정사각형이다. 외부 테마의 명시적 playSize는 유지한다. 보조 버튼 유리는 InsetDrawable로 작게 보이게 하되 네이티브 버튼/입력 영역은 48dp로 유지한다. 시간/도구 텍스트는 내용 높이로 배치해 큰 글꼴이 늘어날 수 있게 했다.
- 어비스 탐색선은 1dp와 작은 발광점으로 정리했다. 세로 십자선만 생략하며 기존 파형 옵션/A–B 표시와 드래그 재생·놓을 때 탐색 동작은 유지한다.
- AGSL의 화면 전체 밝은 선 패턴을 제거했다. 추가 빛은 수면 상단 또는 측면의 이미지 질감 경계에 제한하고 강도를 낮췄다. 중앙 수역에는 그물 형태를 더하지 않는다. 원경 굴절 진폭도 축소했다.
- 빛줄기는 가로·세로 그라데이션을 합성해 부드러운 가장자리로 그리고, 원경/전망창에 정적인 주변부 음영을 추가했다. 기존 이미지의 정적 조명은 그대로다.

## 보존 및 검증 범위

음악/라이브러리/테마 저장 형식, 오디오·PCM·USB·볼륨 구현, bit-perfect 판정은 변경하지 않는다. API33+ 광학 효과와 API31–32/실패 시 Canvas 표시 정책, 효과 OFF, 화면 이탈 시 프레임 콜백 중단은 유지한다. ORIGINAL/화현의 기본 치수와 탐색 그림을 유지한다.

자동 테스트는 너비 대비 창 지름, 최소 높이/스크롤 우선, 창과 앨범 영역 및 앨범 터치를 검사한다. 앱의 실제 View 배치나 GPU 셰이더 컴파일/출력 검증을 대신하지 않는다. 이 개발 환경에는 연결 Galaxy/에뮬레이터 시스템 이미지가 없다.

## 설치 후 확인

1. 기존 앱 위에 설치하고 어비스·기본 강도로 적용한다. 시안 및 이전 녹화와 창 크기/앨범 비율을 비교한다.
2. 큰 창 아래 가사·A–B가 한 화면에 다 보이지 않으면 아래로 스크롤한다. 화면이 짧거나 글꼴이 크면 정상적으로 필요한 동작이다.
3. 중앙 그물무늬가 사라졌는지, 빛줄기에 딱딱한 삼각형 테두리가 보이지 않는지 확인한다. 설정 → 심해 분위기 → 수중 렌더러 상태도 확인한다.
4. 앨범 원의 노출 부분 터치/닫기, 연속 곡 변경, 탐색/A–B/볼륨, 가로 감상/ORIGINAL·화현 복귀를 확인한다.
5. 같은 위치에서 7~10초 녹화하면 다음 해파리·기포 보정의 기준으로 사용할 수 있다. 실제 프레임/발열/메모리 측정과 DAC 샘플 검증은 별도다.
