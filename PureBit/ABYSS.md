# ABYSS · 심연 — v1.7.0

v1.6 실기기 녹화에서 확인한 질감 차이와 하단 밀림을 바탕으로 원경/창 내부 전용 이미지를 재구성하고 배치를 압축했다. 큰 기포와 해파리는 작고 은은하게 조정했다. [ABYSS_MATERIALS.md](ABYSS_MATERIALS.md)에 실제 구현과 확인 범위를 구분한다.

실기기 녹화를 바탕으로 너비 우선의 큰 전망창, 작은 보조 유리, 부드러운 조명으로 구도를 보정했다. 자동 높이와 스크롤 정책/설치 후 확인은 [ABYSS_COMPOSITION.md](ABYSS_COMPOSITION.md)를 참고한다.

수중 광학과 생물/기포 동작을 재작업했다. 새 투명 해파리·기포 자산, 비대칭 추진/회복, 촉수 지연, 크기별 상승과 변형을 적용한다. AGSL 지원·실패 처리·물리 재현의 한계는 [ABYSS_LIVING_OCEAN.md](ABYSS_LIVING_OCEAN.md)를 참고한다.

전용 화면 배치, 독립된 전경 바위/기포, 갓과 촉수가 변형되는 해파리 모션을 추가했다. 배경의 고정 해파리를 제거해 해파리 효과 OFF가 화면 전체에 적용된다. 구현 범위와 실기기 비교 방법은 [ABYSS_RECONSTRUCTION.md](ABYSS_RECONSTRUCTION.md)를 참고한다.

## v1.3.1 실사풍 디테일과 버튼 수정

넓은 USB Direct 강조 버튼은 primary=true였기 때문에 기존 circular 분기의 타원 반사 호가 버튼 안에 길게 그려졌다. AbyssGlassGeometry는 round 요청과 실제 bounds 비율을 함께 검사한다. 약 1:1인 컨트롤만 원형 반사 호를 사용하며, 긴 강조 버튼은 pill 외곽의 약한 반사만 표시한다. 오디오 모드 로직은 수정하지 않았다.

해파리는 새로 생성한 투명 RGBA 질감으로 표현하며 기존 수축/흔들림에 연결한다. 1/2 해상도로 프로세스 내 공유해 매 프레임 decode하지 않는다. 이미지 부재 시 기존 벡터 대체 그림을 사용한다. 이는 photorealistic sprite 연출이고 실제 유체/생체 시뮬레이션이 아니다.

전망창 유리는 cached radial gradient로 어두운 굴절 띠/청록 두께/밝은 가장자리를 겹친다. 기포는 내부 radial 명암과 반사점을 사용한다. 시안의 모든 시각 디테일을 그대로 재현한 것으로 표시하지 않는다. 외곽 원형 앨범과 기존 확대/역전환은 유지한다. 해파리 애니메이션/기포/움직이는 빛 설정을 계속 따른다.

기기 확인: 설정의 넓은 USB Direct 버튼 내부 호가 없어졌는지, 재생/볼륨 원형 버튼의 반사가 유지되는지, 해파리 밝기/투명도와 표지 주변 유리의 과도한 발광 여부. 60 FPS/발열은 기기 측정 전이다.

## v1.3.0 마무리

가사를 어비스 유리 패널로 구성하고 큰 글꼴의 timed 가사도 스크롤 가능하게 했다. 집중 가로 가사는 전망창을 왼쪽, 가사 패널을 오른쪽에 배치한다. 세로/가로 몰입 화면에는 재생 제어와 드래그 종료 시 확정하는 탐색, A–B 메뉴, 가사 진입이 있다. 메인과 같은 엔진의 scrub token을 사용한다. source 세대 변경/앱 이탈에서는 취소한다.

몰입 조작부는 기본 5초 후 숨기고 첫 터치를 복원에 사용한다. 돌아가기 버튼은 유지한다. 숨김은 설정에서 끌 수 있고 reduced motion/터치 탐색에서는 작동하지 않는다. 포커스 가사에도 이 설정을 반영한다. 표준 Android Back도 유지한다.

심해 분위기는 고요한/발광 프리셋과 효과별 0/0.55/1/1.5 강도를 제공한다. Android private preferences에 개별 저장하고 기존 설정이 없으면 1배다. 배경/전경/전망창/가사/오프닝/표지 확대에 설정을 전달한다. 정적 배경의 빛은 남지만 해파리는 별도 레이어로 끌 수 있다. 파동 OFF는 detector도 초기화한다. 사용자 설정이 PCM으로 전달되지 않는다.

실기기 최종 확인은 ABYSS_FINAL_CHECKLIST.md. 장시간 측정은 이 개발 환경에서 수행하지 않았다.

## v1.2.3 유영과 곡 전환

작은 원의 표지 교체는 약 750ms crossfade와 1.1초 기포를 사용한다. CoverFade는 이전/현재 bitmap을 빌려 참조하며 recycle하지 않는다. 빠른 변경은 시각적으로 우세한 표지에서 최신 대상으로 전환한다. 같은 bitmap 재전달은 애니메이션을 다시 시작하지 않는다. 이전 참조는 전환 완료/화면 비활성에서 해제한다. 배경의 큰 전망창은 유지하고, 표지가 없는 곡은 기존 placeholder로 전환한다. 애니메이션 OFF에서는 즉시 표시한다.

해파리는 몸체 폭/높이 수축과 촉수별 위상 지연으로 유영한다. 각 개체는 서로 다른 시간 배율로 움직이며 기존 전망창 내부 clipping에서도 보인다. 빛줄기는 상단에서 아래로 사라지는 gradient를 적용해 하단 조작 영역의 밝기를 절제한다. 모두 UI이며 PCM과 USB 처리는 유지한다.

기기 확인: 연속 NEXT/이전, 표지 유무가 다른 곡 사이 전환, 재생 중 테마 변경, 가로 감상, 앨범 확대 중 곡 전환, 시스템 애니메이션 OFF. 이전 표지가 남거나 기포가 글자를 과하게 가리지 않는지 확인한다. 실제 60 FPS/메모리 사용은 측정 전이다.

## v1.2.2 깊이와 파동

기포·부유물의 3개 거리 층은 AbyssDepth의 결정적 좌표를 재사용 배열로 계산한다. 먼 것은 작고 느리게, 중간 기포는 선명하게, 앞쪽 기포는 캐시한 radial gradient와 matrix로 흐리게 그린다. 실시간 blur나 마이크 분석을 사용하지 않는다.

AbyssRipples는 기존 SpectrumAnalyzer가 읽은 source PCM 저역의 상승을 감지한다. adaptive baseline/최소 상승/220ms cooldown을 사용하며 4개 고정 슬롯에 파동을 저장한다. 파동은 1.65초 동안 바깥으로 퍼지고 밝기가 감쇠한다. 일정한 큰 입력은 반복 트리거하지 않는다. source 변경/화면 비활성/일시정지/반응 OFF에서는 상태를 초기화해 오래된 파동이 다시 나타나지 않게 한다. 기존 BassPulse를 쓰는 ORIGINAL/화현은 유지한다.

추가 기기 확인: 저음이 강한 곡에서도 링이 계속 최대 밝기로 남지 않는지, 드럼 타격과 파동이 어울리는지, 조용한 곡의 과도한 반응 여부, 일시정지/곡 변경/반응 OFF 뒤 파동이 남지 않는지, 앞쪽 기포가 글자와 조작을 과하게 가리지 않는지. 60 FPS는 측정 전 목표다. 해파리 고급 모션과 별도의 곡 전환 기포 무리는 이번 범위에 추가하지 않았다.

## v1.2.1 추가 사항

시안의 큰 전망창에 가깝게 portrait 원 지름과 좌우 여백을 조정했다. 기존에 저장된 외부 schema2 테마의 명시적 여백은 보존한다. 내장 ABYSS는 새 기본값을 사용한다. 이전/다음/재생/일시정지 glyph를 Canvas로 그려 폰트에 따른 모양 차이를 줄였다. 주변 transport와 내비게이션 배경은 비활성 시 투명하게, 중앙 재생은 유리 가장자리와 반사광으로 강조한다. 상단은 얇은 글자와 어두운 gradient로 가독성을 보완한다.

입장의 마지막 구간에서 전망창을 등장시키고 실제 재생 Deck 영역의 좌표/크기로 이동시킨다. 배경/원/재생 장면은 공통 수중 시계를 사용한다. 서명/브랜딩을 먼저 걷어내고 전망창이 정착한 뒤 화면이 열린다. 설정에서 실행하는 미리보기는 재생 화면이 보이지 않으면 전체 화면을 landing 영역으로 사용한다. 실제 알파 합성·회전·스크롤 위치는 기기 검증 대상이다.

앨범은 부드러운 곡선 경로로 이동하고, 위치가 정착하기 전에 원본 crop을 늦게 해제한다. 기포는 유리 외곽을 따라 생기며 열기/닫기 모두 시간 기준으로 위로 이동한다. 기포 밝기는 양 끝에서 0으로 내려간다. 이동을 되돌리거나 앱을 나가는 정리 동작은 기존 것을 유지한다.

기기 추가 확인: 전체 입장 마지막 원이 튀지 않고 연결되는지, 확대 중 바로 닫기/뒤로 가기, 매우 긴 세로/가로 표지, 확대 중 잠금, ORIGINAL/화현 복귀. 이번 버전은 시안의 모든 입자/물리 굴절/해파리 모션을 완전히 재현했다는 뜻은 아니다.

## 시각 구성

큰 유리 전망창에는 심해 원경을 유지하고, 작은 원형 앨범아트를 오른쪽 아래 뒤편에 배치한다. 큰 원을 나중에 그려 앨범의 일부를 가린다. 앨범은 회전하지 않는다. 표지가 없어도 심해 전망창은 유지한다. 앱 전체에는 심해 배경, 빛줄기, 기포/부유물, 느리게 이동하는 해파리를 표시한다.

앨범 원 터치 시 같은 bitmap을 원형 crop에서 원본 비율의 둥근 사각 유리 패널로 약 0.9초 동안 확대한다. 테두리 주변의 기포를 동반하며 터치/뒤로 가기로 반대로 닫는다. 표지의 모서리까지 최종 표시한다. 확대 중에도 음악은 계속 재생한다. 곡 변경/앱 이탈/Activity 종료 시 확대를 정리하고 원래 원을 복원한다. 애니메이션 OFF/터치 탐색에서는 즉시 열고 닫는다. 실제 기기에서 전환 속도와 배치를 확인해야 한다.

전체 입장은 11초, 짧게 1.8초, 끄기와 터치 건너뛰기를 지원한다. 수중 배경의 카메라 이동, 기포, ABYSS와 김백현 & Codex 서명을 사용한다. 원본 계획의 정교한 수면→전망창 형태 연결은 이 첫 구현에서 전체 장면 fade로 연결한다.

## 적용

기존 앱 위에 업데이트한 뒤 설정 → 테마 및 시작 연출 → ABYSS · 심연 → 미리보기 · 적용. ORIGINAL/화현으로 언제든 돌아갈 수 있다. 새 설치에서도 ORIGINAL이 기본이다. 오프닝 다시 보기로 입장을 확인한다.

기포 수는 테마 화면의 부유물 양, 저음 파동은 빛과 움직임의 bass pulse 설정, 전경 터치 기포는 버튼 클릭과 연결한다. 60 FPS 목표이며 S26 Ultra의 실제 frame time/발열은 이 개발 환경에서 측정하지 않았다.

## 구현 위치

- theme/packs/AbyssPack: 재생 레이아웃과 공통 PlayerAction 연결.
- theme/abyss/AbyssScene: 배경/전망창/앨범 위성/기포/해파리/파동.
- theme/abyss/AbyssAlbumView: 원형→원본 비율 패널과 역방향 전환, 애니메이션 해제.
- theme/abyss/AbyssGeometry: 공통 히트 영역과 도형 계산.
- theme/abyss/AbyssGlass: 네이티브 버튼/패널에 적용하는 유리 drawable.
- assets/abyss/ocean.png: 전용 생성 배경. 앨범 표지나 UI가 합쳐진 스크린샷이 아니다.

렌더링은 원본 PCM의 기존 읽기 전용 시각화 분석 결과를 사용한다. PCM/볼륨/SRC/DSP/USB/native 전송 코드는 변경하지 않는다. 심해의 빛은 출력 경로 인증을 의미하지 않으며 BIT-PERFECT NOT VERIFIED를 유지한다.
