# ABYSS v1.7.0 — 시안 기반 질감 재작업

사용자가 보낸 `Screen_Recording_20261019_193449.mp4`(약 5.807초, 1080×2340)를 2초 시점 및 시간별 프레임으로 확인하고 승인된 7210.jpg 시안과 비교했다. v1.6.0은 창을 키웠지만 매끈한 협곡/빈 중앙/과도한 전경/하단 조작부 밀림이 남았다. 이번 변경은 원경과 창 내부 자산을 분리해 다시 만들고 기본 화면의 세로 여백을 줄인다.

## 자산과 시각 변경

- `abyss/ocean.png`: 승인된 시안을 참조해 거친 암벽/작은 돌출부/깊은 청록 수역을 재구성한 세로 원경. 생성 과정의 이중 수면 흔적은 추가 이미지 편집으로 제거했다.
- `abyss/portal.png`: 창 내부 전용 정사각형 풍경. 바닥 자갈과 계단처럼 이어지는 암벽, 빛이 닿는 먼 협곡을 포함한다. 원경을 확대 crop하던 동작을 대체해 가까운 바닥부터 먼 수역까지 보인다. 이미지가 없으면 원경을 사용한다.
- 두 이미지는 시안 기반 재생성 자산이며 시안의 픽셀을 정확히 추출한 파일이 아니다. 이미지에는 UI/기포/해파리가 없고 동적 레이어는 앱에서 별도로 그린다.
- 기존 별도 전경 바위의 불투명도를 줄여 새 질감을 덮지 않게 했다. 큰 기포는 화면상 크기를 70%, 반사/투영 강도를 낮췄다. 해파리는 청록 tint와 작은 최대 크기로 조정했다. 생체/부력 모션 곡선은 유지한다.

## 배치 변경

- v1.6의 과한 높이/지름을 보정한다. 자동 hero 최소 높이는 콘텐츠 너비×0.98(240~520dp), 창 반지름은 콘텐츠 너비×0.45 이하. 기본 16dp 여백의 360~480dp 휴대폰에서는 계산상 화면 너비 약 82~84%의 지름이다.
- 어비스 기본 재생 버튼 64dp, 하단 내비게이션 56dp. 보조 입력의 48dp 영역과 외부 테마 명시 치수는 유지한다.
- 기본 글꼴에서 탐색선과 시간을 같은 48dp 모듈로 배치해 20dp를 확보한다. 시간 문구는 탐색선 아래에 있고 터치를 소비하지 않는다. 글꼴 배율 1.15 초과이면 별도 내용 높이 행을 사용한다.
- 외부 테마의 SEEK/TIME 블록이 이웃하지 않으면 기존 독립 블록 순서를 그대로 사용한다. 큰 글꼴/긴 제목/오류/A–B 확장/짧은 화면에서는 여전히 스크롤할 수 있다.
- 타이틀/아티스트/소스와 페이지 아래 여백을 줄였다. 기본 화면 잘림은 실제 S26 Ultra에서 재확인해야 하며 모든 글꼴·화면에서 무스크롤을 보장하지 않는다.

## 확인할 항목

1. 기존 앱 위 설치 후 어비스/기본 효과 강도에서 원경과 창 안의 거친 질감, 창 하단의 자갈이 보이는지 확인한다.
2. 기본 글꼴에서 볼륨/A–B/가사/파일 선택 행이 보이는지 확인한다. 큰 글꼴과 A–B 확장 시 하단까지 스크롤한다.
3. 시간 텍스트 위에서도 드래그를 시작할 수 있고 재생은 계속되며 놓을 때만 탐색이 확정되는지 확인한다. 시스템 접근성 탐색도 확인한다.
4. 표지 원 터치/확대/닫기, 시작 연출 도착, 가로 감상/가사, 연속 곡 변경과 테마 복귀를 확인한다.
5. 효과 OFF 및 수중 렌더러 상태를 확인한다. 7~10초 녹화는 다음 재질/생물 모션 보정 자료가 된다.

이 환경에는 연결 기기/에뮬레이터 시스템 이미지가 없다. 이미지 자산은 직접 보았고 단위 계산/Gradle/Lint를 검사하지만 실제 Android View/GPU 출력과 60FPS·발열·메모리 검증을 대신하지 않는다. 오디오/PCM/USB/하드웨어 볼륨과 bit-perfect 판정은 그대로다.
