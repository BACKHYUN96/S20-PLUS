# ABYSS v1.5.0 — 살아 있는 심해

시안의 재질·공간감을 목표로 한 시각 업데이트다. 30,000원 스킨이라는 기준은 품질 목표이며 유료 판매나 실사/물리 시뮬레이션 인증을 뜻하지 않는다. 승인된 시안은 실행 화면이 아니다. 원형 앨범은 요청대로 전망창 뒤에 유지한다.

## 장면을 구성하는 레이어

1. 원경 해저 협곡: 고정 해파리 없는 이미지, 느린 카메라 드리프트.
2. 수중 광학: Android 13+ 하드웨어 Canvas에서 AGSL로 원경과 전망창 내부 픽셀을 약하게 굴절시키고 이동하는 빛무늬를 합성.
3. 먼 부유물/중간 기포: 좁은 상승 흐름, 작은 반사광, 거리별 크기·불투명도.
4. 해파리: 새 반투명 갓/촉수 이미지, 추진·회복 비대칭 주기와 8×16 변형 mesh.
5. 가까운 바위: 별도 투명 이미지와 카메라 드리프트. 입력 요소 뒤에 유지.
6. 전망창과 원형 앨범, 네이티브 조작부: 유리 재질과 추가 구형 버튼 반사.
7. 가까운 기포/해파리: UI보다 앞의 비상호작용 레이어. 화면 양쪽에 배치.

## 움직임의 기준

해파리 한 주기의 26%는 빠른 갓 수축, 나머지는 느린 회복이다. 이동 거리의 70%가 추진 구간에서 발생하고 회복 때는 관성 유영을 근사한다. 촉수의 변형은 갓보다 최대 0.85초 늦게 반응하며 개체별 주기/기울기/해류 표류를 달리한다. 전 개체가 같은 박자로 커졌다 작아지지 않는다.

기포는 반지름에 따라 상승 속도와 흔들림을 다르게 하고, 상승하며 조금 커지고 큰 기포가 더 눌리도록 한다. 위·아래 경계에서 투명해져 루프 연결을 감춘다. 속도는 정해진 시각 파라미터다. 실제 수심/기체압/점도/표면장력/종별 생체 동역학을 측정하거나 Navier–Stokes 방정식을 푸는 구현은 아니다.

## 지원과 실패 처리

- minSdk31 유지. API31–32 또는 소프트웨어 Canvas는 기존 Bitmap/Canvas 경로를 사용한다.
- API33+에서 RuntimeShader를 시도한다. 생성/사용 중 예외는 잡아서 Canvas로 전환하며 `BitwireTheme` 로그를 남긴다. 그래픽 드라이버 자체 종료까지 복구한다고 보장하지 않는다.
- 설정 → 심해 분위기 → **수중 렌더러 상태**에서 실제 최근 사용 경로를 확인한다. 이 환경에서는 Android 런타임의 AGSL 컴파일·GPU 출력을 실행하지 못했다.
- 빛 효과 OFF는 추가 굴절/빛무늬/빛줄기 강도를 0으로 한다. 원경 이미지에 그려진 정적 조명은 유지한다. 해파리/기포 OFF는 별도 레이어를 제거한다.
- 기존 시스템 애니메이션 OFF/TalkBack/화면 이탈의 프레임 콜백 중단 정책을 유지한다.
- 새 자산은 프로세스당 한 번 축소 디코딩하고 mesh 버퍼를 재사용한다. 60 FPS/발열/메모리는 S26 Ultra 측정 전 목표다.
- 굴절은 원경만 샘플링하며 실제 UI 뒤 픽셀의 광학적 굴절은 아니다. 오디오/PCM/USB/하드웨어 볼륨 처리와 무관하다.

## 설치 후 비교

기존 앱 위에 설치 → 어비스 적용 → 기본 강도. 20초 정도 화면 녹화해 갓 수축/상승/촉수 지연, 기포 경계 루프, 타이틀 가독성을 확인한다. 렌더러 상태도 함께 기록한다. 새 효과를 끄거나 ORIGINAL/화현으로 바꿔 재생·탐색·가사·볼륨이 그대로인지 확인한다. 자세한 회귀 항목은 ABYSS_FINAL_CHECKLIST.md.
