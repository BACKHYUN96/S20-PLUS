# BITWIRE v1.9.0 / code 46 — ABYSS 재생 조작부 재제작

전달된 v1.8.0 실기기 녹화(약 7.01초)와 승인된 ABYSS 시안을 기준으로 재생 조작부의 재질·아이콘·비율을 교체했다. 기존 유리 패널의 색만 바꾸는 방식에서 전용 조작부 표면으로 전환했다.

## 구현

- 재생: 별도 제작한 `abyss/play-orb.png`의 이중 유리 테두리·청록색 반사·어두운 중앙을 사용한다. 재생/일시정지/준비 취소 기호는 상태에 따라 별도로 그린다. 자산을 읽지 못하면 벡터 유리 구체로 표시한다. 기본 터치 크기는 88dp이며 외부 테마의 playSize 설정은 유지한다.
- 이전/다음: 흰색 삼각형과 가는 정지선. 셔플·전체 반복·한 곡 반복은 동일한 선 굵기의 새 경로다.
- 볼륨: 실제 터치는 48dp, 보이는 원형은 28dp. 가운데 장치/볼륨 문구와 함께 화면 너비에 맞춰 중앙에 배치한다. 하드웨어 볼륨 전달 코드는 유지한다.
- A–B/가사: 48dp 터치 영역 안에 높이 24dp의 얇은 캡슐을 그린다. A–B 활성 상태는 색상과 접근성 설명으로 알리고 짧은 이름을 유지한다. 펼치면 기존 A/B/해제 기능이 나온다.
- 탐색: 전용 얇은 선, 흰색 중심과 청록색 발광 손잡이, 양끝 시간 표시. ABYSS 메인에서는 파형 분석을 끄고 기존 SeekBar 입력/드래그 완료 시 탐색/취소 처리는 유지한다. 다른 테마의 파형은 유지한다.
- 하단 메뉴와 설정·전체 화면 아이콘도 새 선형 도안으로 통일한다. 선택 메뉴는 자간 있는 이름과 작은 발광점으로 표시한다.
- 누를 때 조작부 자체의 약한 눌림/테두리 반응을 사용한다. ABYSS 공통 버튼의 클릭 버블 폭발은 제거했다. 기존 장면의 기포·앨범 트랜지션은 유지한다.
- 가로/가사/몰입 화면의 넓은 재생 버튼에서도 구체를 중앙 정원으로 그린다. USB 출력 설정 같은 일반적인 primary 버튼은 구체가 되지 않는다.

## 검증 범위

Gradle 빌드, JVM 회귀 검사, Lint, APK 서명과 정렬을 확인한다. 배경·원형 앨범·음원 데이터·오디오/USB 엔진은 이번 변경 대상이 아니다. 새로운 구체 자산은 시안 분위기를 목표로 제작한 재질이며 원본 시안에서 픽셀 단위로 추출한 버튼이 아니다.

실기기 렌더링·터치·GPU 프레임과 시안 일치도는 S26 Ultra에서 확인해야 한다. 이 환경에는 연결된 Galaxy나 실행 가능한 Android 에뮬레이터 이미지가 없다. 정적인 자산 미리보기는 실제 앱 스크린샷이 아니다.

## 설치 및 확인

기존 앱 위에 업데이트 설치한다. 앱 제거/데이터 삭제가 필요하지 않다.

1. 재생/일시정지/준비 취소 시 구체와 기호가 함께 보이는지 확인한다.
2. 이전/다음/셔플/반복 3상태의 동작과 색상을 확인한다.
3. 탐색 바를 끄는 동안 기존 재생이 유지되고 놓을 때만 이동하는지, 제스처 취소는 이동하지 않는지 확인한다.
4. 볼륨 ±와 USB Direct 하드웨어 볼륨, A–B 설정/해제, 가사 열기를 확인한다.
5. 가로 화면·큰 글꼴에서 버튼/문구가 잘리면 스크린샷을 전달한다. 일반 화면 공간이 부족하면 전망창을 줄이지 않고 스크롤한다.
6. 설정의 USB Direct 버튼이 넓은 패널로 유지되는지, ORIGINAL/화현 테마 복귀가 되는지 확인한다.

음악 추가와 즐겨찾기는 라이브러리의 파일/폴더 추가 및 곡 길게 누르기를 사용한다.
