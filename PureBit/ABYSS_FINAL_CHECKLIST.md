# v1.7.0 ABYSS 실기기 최종 확인

- [ ] 새 원경의 거친 바위와 창 안쪽의 자갈 바닥이 보이고 이중 수면/고정 해파리가 없다.
- [ ] 기본 글꼴에서 볼륨/파일 선택/A–B/가사가 보인다. 부족하거나 큰 글꼴인 경우 하단까지 스크롤된다.
- [ ] 탐색선 아래 시간 문구 위에서도 탐색 드래그를 시작할 수 있다. 놓을 때만 확정된다.
- [ ] 큰 글꼴에서 시간은 별도 행으로 보이고 잘리지 않는다. 외부 테마의 SEEK/TIME 순서도 유지된다.
- [ ] 작은 전경 기포/청록 해파리가 제목·버튼을 과하게 가리지 않는다.

- [ ] 기본 글꼴의 세로 화면에서 전망창이 이전 녹화보다 크고 원형 앨범은 뒤에 작게 겹쳐 있다.
- [ ] 큰 글꼴/A–B 확장/짧은 화면에서는 전망창을 억지로 축소하지 않고 하단 도구까지 스크롤할 수 있다.
- [ ] 중앙에 밝은 그물 형태 패턴이 없고 바위/수면 빛과 부드러운 빛줄기만 은은하다.
- [ ] 작은 보조 유리와 탐색 발광점, 48dp 보조 버튼 영역으로 재생/볼륨/표지/탐색을 조작할 수 있다.

- 시안과 비교: 큰 전망창, 뒤에 겹치는 원형 표지, 제목·탐색·버튼·하단 메뉴의 간격을 확인한다.
- 해파리 OFF에서 해파리가 사라지는지, ON에서 갓과 촉수가 서로 다르게 움직이는지 확인한다.
- A–B 펼침/접기, 큰 글꼴, 가로 화면에서 조작부가 잘리지 않고 스크롤되는지 확인한다.

- [ ] 오디오 출력의 넓은 USB Direct 버튼 안에 긴 반사 호가 나타나지 않는다.
- [ ] 원형 재생/음량 버튼의 유리 반사는 유지된다.
- [ ] 질감 해파리와 렌즈/기포가 과하게 밝지 않고 효과 OFF도 유지된다.

기존 앱 위에 설치한다. 데이터/캐시 삭제 불필요. APK 빌드와 JVM/Lint 검사는 실제 Galaxy의 프레임/메모리/발열 측정을 대신하지 않는다.

## 조작과 감상

- [ ] 어비스 일반/집중 가사, plain 내장 가사와 LRC가 모두 표시된다.
- [ ] 큰 글꼴에서 긴 가사를 스크롤할 수 있다.
- [ ] 가로 감상에서 앨범 원·글자·유리 패널이 카메라 홀/시스템 바에 가려지지 않는다.
- [ ] 세로 몰입과 가로 감상에서 탐색 중 음악이 계속 재생되고, 놓을 때만 이동한다.
- [ ] 탐색 중 스크롤/화면 이탈/곡 변경으로 gesture가 취소되면 이동하지 않는다.
- [ ] 몰입 화면의 A 시작/B 끝/해제와 가사 열기가 동작한다.
- [ ] 5초 후 조작부가 숨겨지고 첫 터치는 복원만 한다. 다음 곡을 잘못 누르지 않는다.
- [ ] 돌아가기 버튼과 Android Back은 계속 동작한다.
- [ ] 조작부 숨김 OFF/애니메이션 OFF/TalkBack에서 필요한 버튼이 숨지 않는다.

## 취향과 회귀

- [ ] 고요한 심해/발광 심해 선택 후 효과별 강도가 즉시 바뀐다.
- [ ] 기포/해파리 애니메이션/움직이는 빛/저음 파동을 개별 OFF할 수 있다.
- [ ] 배경의 정적 빛은 남지만 해파리 OFF에서는 해파리가 모두 사라진다.
- [ ] 수중 굴절·빛줄기 OFF에서 움직이는 굴절과 추가 빛무늬가 사라진다.
- [ ] 설정 → 심해 분위기 → 수중 렌더러 상태를 기록한다. AGSL 실패 시에도 화면과 음악이 계속 동작한다.
- [ ] 해파리가 짧게 수축하며 상승한 뒤 천천히 회복하고 촉수가 뒤따른다. 순간이동/규칙적인 통째 확대·축소가 두드러지지 않는다.
- [ ] 큰 기포는 작은 기포보다 빠르게 오르며 좌우 흔들림과 약한 눌림이 보인다. 화면 안에서 갑자기 새 기포로 바뀌지 않는다.
- [ ] 재시작 후 효과 강도가 유지된다. 기본 강도 복원과 ORIGINAL/화현 전환도 동작한다.
- [ ] 앨범 원 확대/역전환, 연속 다음 곡, 표지 없는 곡이 정상이다.
- [ ] 48/96 kHz USB 재생, 하드웨어 볼륨, 잠금/재연결이 이전처럼 동작한다.

## 장시간 확인 — 개발 환경에서 미실행

- [ ] 화면 켠 채 30분 이상 재생하고 조작 지연/프레임 저하/발열을 기록한다.
- [ ] 표지 확대/가사/가로 모드를 반복한 뒤 메모리 증가나 강제 종료가 없는지 확인한다.
- [ ] 잠금/다른 앱 전환 후 돌아오면 숨겨진 조작부와 탐색 상태가 복원된다.
- [ ] 문제 발생 시 앱 내부 데이터 진단 파일과 사용한 테마/효과/곡 포맷/동작 순서를 함께 남긴다.

60 FPS는 목표이며 이 목록을 통과하기 전 측정 완료로 표시하지 않는다. 장치 수신 PCM/bit-perfect 판정은 별도의 검증 범위다.
