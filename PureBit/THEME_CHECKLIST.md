# v1.1.0 테마 구조 변경 — 기기 확인

기존 앱 위에 업데이트한다. 데이터/캐시 삭제는 필요 없다.

- [ ] 기존 선택 테마와 음악 라이브러리/즐겨찾기/대기열이 유지된다.
- [ ] ORIGINAL ↔ 화현 전환 후 버튼, 탐색, A–B, 음량, 가사, 라이브러리, 설정이 동작한다.
- [ ] 재생 중 테마 전환으로 곡이나 위치가 초기화되지 않는다.
- [ ] 예전 schema=1 월백 파일을 가져오고 적용할 수 있다.
- [ ] 제공한 화현 스튜디오 파일을 가져오면 제목이 위로, 재생 버튼이 탐색 바 위로 이동한다.
- [ ] 기본 화현으로 돌아오면 원래 배치가 복원된다.
- [ ] 큰 글꼴과 가로 회전 후 터치 영역/시스템 바가 정상이다.
- [ ] 잘못된 레이아웃 파일을 거부하고 현재 테마를 유지한다.
- [ ] 앱을 종료하고 다시 열어도 선택한 외부 테마가 복원된다.

테마는 시각 연출이며 DAC 샘플 검증이나 USB 지원 포맷을 바꾸지 않는다.
